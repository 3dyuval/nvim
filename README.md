# Neovim config

Graphite/HAEI layout, Fennel-authored (compiled to Lua via nfnl).

## Source of truth

- **Movement / keymap model** → [`SPEC.md`](./SPEC.md). The HAEI directional
  system, granularity layers, and conflict/precedence rules live there.
  Do not re-document keymaps elsewhere; derive from the SPEC + the code.

## Hard requirements

- **Fennel is the source.** Edit `fnl/**/*.fnl`; the `lua/**` twins are
  generated by nfnl (on save) / `make compile`. Never hand-edit a generated
  `lua/` file — the change is lost on next compile. A few `lua/` files are
  hand-written (no `.fnl` twin): `config/keymaps.lua`, `config/keymaps-old.lua`,
  `config/options.lua`, `config/lazy.lua`, most of `lua/plugins/`, `lua/utils/`.

- **Before committing, run:**
  ```bash
  make format    # stylua (lua) + prettier (js/ts)
  make compile   # fnl -> lua (or rely on nfnl-on-save)
  make test      # plenary + keymap-conflict checks
  ```

- **No keymaps in `lua/utils/`** — utils are focused, reusable, testable
  modules; keymaps live under `fnl/config/keymaps/`. Separation of concerns.

- **Commits are commitlint-validated:** one line, subject + type, no emojis.

## Layout

```
fnl/        Fennel sources (authoritative)
lua/        Generated + hand-written Lua
SPEC.md     Movement/keymap vision + invariants
```
